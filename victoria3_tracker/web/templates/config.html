Configuration Help

Save Directory

This is the most important setting. The tracker monitors this directory for new Victoria 3 save files (.v3 extension). Make sure:

  • The directory exists and is accessible
  • Victoria 3 is configured to save autosaves to this location
  • The tracker has read permissions for this directory

Performance Settings

Adjust these settings based on your system performance:

  • Polling Interval: Lower values detect new saves faster but use more CPU
  • Max File Size: Larger saves take longer to process
  • Processing Timeout: Increase for very large save files

Troubleshooting

If you're having issues:

  • Set log level to DEBUG for detailed information
  • Check that rakaly.exe is available and working
  • Ensure the web port is not used by another application
  • Verify Victoria 3 save directory permissions
